# Planning & Interview Protocol

1. **Clarification First:**
   - When Plan Mode is active, do not draft the final plan immediately if key assumptions exist.
   - First, present 2–4 targeted questions covering edge cases, dependencies, and UX/API design.

2. **Plan Content Requirements:**
   - Every generated plan must explicitly include:
     - Proposed architecture and affected files.
     - Testing strategy (which tests will be added/updated).
     - Non-goals (what is intentionally out of scope).

3. **No Execution Without Approval:**
   - Never create, edit, or delete source files while in Plan Mode.
   - Wait for explicit user confirmation on the plan artifact before starting execution.
